Detailed Description

Основной контроллер игры RogueLike.

Отвечает за связь между пользовательским вводом, моделью игры и представлением. Получает команды от слоя ввода, вызывает соответствующие методы модели и инициирует обновление отображения.

Класс относится к слою Controller в архитектуре MVC.
