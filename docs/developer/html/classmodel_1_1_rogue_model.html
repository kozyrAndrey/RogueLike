Detailed Description

Основная модель игры RogueLike.

Хранит текущее состояние игровой сессии, управляет игроком, уровнем, системой ходов, журналом событий, статистикой прохождения и сохранениями. Класс является центральной частью слоя Model в архитектуре MVC.

Основные обязанности:

  • запуск новой игры;
  • обработка движения игрока;
  • переход между уровнями;
  • использование предметов;
  • сохранение и восстановление игровой сессии;
  • формирование состояния для отображения во View.
