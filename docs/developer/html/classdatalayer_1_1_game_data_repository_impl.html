Detailed Description

Реализация репозитория игровых данных.

Отвечает за сохранение и восстановление состояния игры, работу с локальными файлами и хранение статистики игровых попыток. Используется слоем модели для поддержки продолжения последней сессии и отображения таблицы результатов.
