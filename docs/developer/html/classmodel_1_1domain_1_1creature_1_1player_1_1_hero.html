Detailed Description

Класс игрового персонажа.

Хранит имя игрока, характеристики героя, количество сокровищ, ключи, рюкзаки для разных типов предметов, экипированное оружие и активные временные эффекты.

Класс реализует предметную модель игрока и используется в игровой логике, боевой системе, инвентаре, сохранениях и отображении состояния.
