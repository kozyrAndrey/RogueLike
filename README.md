# JavaRogue

Классическая rogue-like игра, написанная на Java. Исследуйте процедурно генерируемые подземелья, сражайтесь с монстрами, собирайте сокровища и управляйте инвентарем в этой текстовой RPG.

## 🧩 Мой вклад в проект

- **Сохранения и восстановление прогресса (JSON, data layer)**: реализовала слой хранения данных; автосохранение после прохождения уровня; возможность продолжить последнюю сессию после перезапуска с полным восстановлением состояния; сохранение истории всех попыток для отображения лучших прохождений в таблице лидеров.
- **Игровая прогрессия уровней**: при достижении выхода персонаж автоматически переходит на следующий уровень; сохранение номера пройденного уровня и связанной статистики.
- **Статистика прохождений и лидерборд**: сбор и отдельное представление статистики попыток.
- **Туман войны**: начальная реализация; логика отображения зависит от состояния игры — неизведанные зоны скрыты, текущая комната и область прямой видимости отображаются благодаря ray casting и алгоритму Брезенхэма.
- **Улучшение рюкзака**: упрощение использования рюкзака.

## 🎮 Особенности проекта

- **Процедурная генерация уровней** - Уникальные подземелья при каждом запуске
- **Сложная боевая система** - Шанс попадания на основе ловкости, урон на основе силы
- **Система инвентаря** - Оружие, еда, эликсиры, свитки
- **Развитие персонажа** - Система характеристик (Здоровье, Сила, Ловкость)
- **Разнообразные враги** - 6 типов противников с уникальным поведением
- **Система предметов**:
    - Оружие (экипировка/снятие)
    - Еда (восстановление здоровья)
    - Эликсиры (временные усиления)
    - Свитки (постоянные улучшения)
- **Система ключей и дверей** - Три цветных ключа для запертых дверей
- **Игровой лог** - Отслеживание событий в реальном времени
- **ASCII-графика** - Классический терминальный интерфейс

## 🛠 Технологии

- **Java 21**
- **Gradle 8.0+** - Система сборки
- **Lanterna 3.0** - Библиотека для терминального UI
- **Архитектура MVC** - Паттерн Model-View-Controller
- **Фабричный паттерн** - Для генерации врагов и предметов

## 🎯 Управление

### Движение:
- `W` - Движение вверх
- `A` - Движение влево  
- `S` - Движение вниз
- `D` - Движение вправо

### Навигация в меню:
- `Стрелки` - Перемещение по меню
- `Enter` - Выбор опции
- `Escape` - Назад
- `Q` - Выход из игры

## 🏹 Игровой процесс

### Боевая система:
- Шанс попадания рассчитывается из ловкости атакующего и цели
- Урон зависит от силы и модификаторов оружия

### Характеристики персонажа:
- **Здоровье (HP)** - При достижении 0 - игра заканчивается
- **Сила** - Влияет на наносимый урон
- **Ловкость** - Влияет на шанс попадания и уклонения

### Типы предметов:
- **Оружие** - Увеличивает силу при экипировке
- **Еда** - Мгновенно восстанавливает здоровье
- **Эликсиры** - Временные усиления характеристик (60 ходов)
- **Свитки** - Постоянные улучшения характеристик
- **Сокровища** - Дают золото
- **Ключи** - Открывают соответствующие двери
